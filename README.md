# Редактор шаблонов Авито

Графическое приложение для редактирования шаблонов выгрузки объявлений Авито.

## Функционал

### Вкладки

- **Инструкция** — статичная страница с правилами работы
- **Настройки** — управление списками по умолчанию (контакты, телефоны, адреса, компания, почта)
- **Редактор** — загрузка XLSX, табличное редактирование, валидация, генерация ID
- **Фото и Экспорт** — создание ZIP-архива с фотографиями

### Бизнес-логика

- Автогенерация уникального ID (до 100 знаков, цифры, буквы RU/EN, символы)
- Валидация названия (до 100 символов, первая буква заглавная, запрещены "цена", "продам", "тел")
- Автоформатирование описания в CDATA с заменой переносов строк на `<br>`
- Парсинг категории из 1-й строки Excel
- Автозаполнение из настроек
- Фиксированные списки для выпадающих значений
- Проверка лимита 50 000 объявлений
- Проверка размера ZIP + XLSX (не более 100 МБ)

## Установка

```bash
go mod tidy
```

## Сборка

```bash
go build -o AVITOUO.exe .
```

## Запуск

```bash
go run .
```

Приложение откроется в браузере по адресу `http://localhost:8080`.

## Технологии

- Go 1.26+
- net/http (встроенный веб-сервер)
- github.com/xuri/excelize/v2 (работа с XLSX)
- archive/zip (создание ZIP-архивов)
